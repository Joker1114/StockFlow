# 给 Codex 的开发指令

请完整阅读同目录 `SDD.md`，按其要求开发“物资通 StockFlow”MVP。**技术栈严格固定：uni-app + Vue3 + TypeScript（Android/iOS）、FastAPI（Python）、云服务器上的 SQLite**。不要擅自换成 Flutter/PostgreSQL、增加 Redis/复杂权限/微服务/Web 后台。

## 执行要求

1. 若仓库为空，按 SDD 建立 `frontend/` 和 `backend/`，写出可运行代码，不提供伪代码。
2. 优先实现后端，先通过 API 测试；使用 Python 标准库 sqlite3，写操作用 `BEGIN IMMEDIATE` 并保证 SQLite WAL、单据幂等、防超库存、安全扫码码状态检查。
3. 完成 APP：登录、首页快捷入口、入库/出库编辑、库存查询、单据列表/详情、管理员基础维护。用 `uni.scanCode` 做真实扫码；无法扫码时提供手动粘贴文本入口，方便模拟器测试。
4. **只实现 SDD 列出的功能。** 颜色、布局保持整洁、简洁、适合手机触控，不做多余动效或大型组件库。
5. 加入可运行的后端自动化测试，特别测试并发库存、防重复提交、一物一码流转、身份权限。
6. 提供 `.env.example`、README 和生产部署说明（数据库持久化、HTTPS 反向代理、一致性备份）。不要把私钥、密码写死在源码中。
7. 每完成一个阶段运行格式/类型检查、可用的测试和构建，修复错误后继续下一阶段；若环境缺失 Android/iOS SDK、macOS/Xcode 或 HBuilderX，不得虚构构建成功，写清楚具体手工验证方法。
8. 最终回答列出：已实现功能、项目目录、运行命令、自动化测试结果、未能验证的事项；不要只声称任务完成。

## 范围限制

第一版固定为一个共享仓库、管理员和普通用户两角色。没有支付、审批、财务、报表、云对象存储、离线同步、在线鉴伪，也不开发独立管理网站。

## 开始

现在直接从**阶段一：FastAPI + SQLite 后端**开始，继续完成整个 MVP，无需重复询问已在文档中确定的技术选型。
